## 1. What I Learned in the Bootcamp So Far

- Backend & Web Concepts: I learned how the Client and Server communicate through HTTP requests and responses. I also learned about JSON, status codes, REST APIs, endpoints, HTTP methods, middleware, authentication, validation, and how a request moves through the backend before the response is returned.

- JavaScript Fundamentals & ES6+: I started with variables, data types, conditions, loops, and functions. Then I worked more with Arrays and Objects using methods such as map, filter, find, and reduce. I also learned Destructuring, Spread, Set, Date, and Error Handling.

- Advanced JavaScript: I learned the basics of OOP including classes, constructors, inheritance, and method overriding. I also studied Timers, Promises, fetch, async/await, the Event Loop, tasks and microtasks, and the basics of Regex.

- TypeScript: I learned how TypeScript adds types to JavaScript and worked with Type Inference, Union Types, Literal Types, Type Aliases, Interfaces, typed functions, Arrays, and Objects.

- Node.js & Ecosystem: I learned that Node.js allows JavaScript to run outside the browser and studied V8, libuv, Non-Blocking I/O, and the Event Loop. I also learned how to create an HTTP server with node:http, the difference between CommonJS and ES Modules, and the basics of Express including routes, endpoints, handlers, and middleware.

- Git & GitHub: I learned the Git workflow from the working directory to staging, local repository, and remote repository. I practiced commits, branches, push, fetch, merge, and working on separate branches as part of a team. I also became more comfortable using basic CLI commands.
